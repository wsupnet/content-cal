# ContentCal backend regression tests

Run from the `backend/` directory with `pytest` (after `pip install -r requirements-dev.txt`). The suite uses `fastapi.testclient.TestClient` against the real FastAPI app and never touches the production sqlite DB: `tests/conftest.py` sets `DATA_DIR`/`DB_FILE`/`SESSION_SECRET` to a fresh temp directory before importing `main`, monkey-patches the hardcoded `/frontend` static-file mount to a stub directory, and drops + recreates every table between tests via a function-scoped `reset_db` fixture (so each test is independently runnable, in any order). Use `client` for a single TestClient or `make_client` for a factory when you need multiple cookie jars (e.g. two-user scenarios); `two_users_shared` returns an owner + member already joined into the same workspace via invite.
